# گزارش‌های فنی — سیستم کاربران، نقش‌ها، مجوزها و ردیابی فعالیت‌ها

این پوشه زیرمجموعه مستندات فنی پروژه است و به‌صورت مستقل تمام تصمیم‌ها، طراحی‌ها، بررسی‌ها و گزارش‌های فنی مربوط به هسته مرکزی کاربران سامانه را نگهداری می‌کند.

## دامنه

- احراز هویت کاربران (Authentication)
- کاربران و حساب‌ها (Users / Accounts)
- نقش‌ها (Roles)
- مجوزها (Permissions)
- موتور مرکزی مجوزها (Permission Engine)
- نشست‌ها و وضعیت حساب
- کنترل دسترسی بخش‌های مختلف سامانه
- تفکیک وظایف و مسئولیت‌ها
- ردیابی فعالیت‌ها و Audit Log
- اتصال کنترل کیفیت داده به سیستم مرکزی کاربران
- امنیت دسترسی و RLS/Authorization
- مسیر توسعه آینده مدیریت کاربران

## اصل معماری

کاربر متعلق به یک ماژول خاص نیست. هر کاربر یک هویت مرکزی در سامانه دارد و دسترسی او از طریق Role و Permission تعیین می‌شود.

کنترل کیفیت داده نیز یکی از مصرف‌کنندگان همین هسته مرکزی است و سیستم کاربران مستقل از آن طراحی می‌شود.

## وضعیت

- مرحله فعلی: طراحی معماری
- پیاده‌سازی عملی: شروع نشده
- تغییر در Supabase/Auth/RLS/Policy: انجام نشده
- تغییر در جدول `martyrs`: انجام نشده
