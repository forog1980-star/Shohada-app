## 8. معماری رسمی

معماری اتصال باید از این الگو پیروی کند:

```
Search
  ↓
Resolver
  ↓
Index
  ↓
Loader / Connector
  ↓
Golzarteh Data
  ↓
UI
```

وظیفه‌ها باید از هم جدا باشند:

- Search = پیدا کردن رکورد داخلی
- Resolver = تشخیص رکورد متناظر
- Index = نگهداری رابطه
- Loader = دریافت اطلاعات تکمیلی
- UI = نمایش
