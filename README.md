سامانه مدیریت و پایش بهسازی سنگ‌های شهدای گلزار شهدای تهران

## هدف

ثبت، بررسی و مدیریت وضعیت سنگ مزار شهدا توسط ناظر میدانی و ناظر سایت.

- سادگی حداکثری برای ناظر میدانی
- اولویت نسخه موبایل
- ثبت شهید جدید از طریق موبایل
- جستجوی سریع اطلاعات شهید
- ثبت وضعیت فعلی سنگ با یک انتخاب ساده
- تأیید اطلاعات توسط ناظر سایت
- نگهداری بانک اصلی در پایگاه داده
- خروجی Excel
- امکان خروجی کل اطلاعات یا تفکیک‌شده بر اساس قطعه
