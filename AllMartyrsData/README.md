# AllMartyrsData

داده‌های مستقل ماژول «جستجوی کل شهدا» در این پوشه قرار می‌گیرند.

## منابع

- `golzar_martyrs.xlsx` — شهدای ثبت‌شده در قطعات داخلی گلزار
- `outside_golzar_martyrs.xlsx` — شهدای قطعات عمومی خارج از محدوده داخلی گلزار

این دو فایل مستقل از `ExcelData/martyrs_master_v2.xlsx` هستند و نباید با داده عملیاتی سامانه ادغام شوند.

## قواعد داده

- رکوردهای تکراری حذف نمی‌شوند.
- رکوردهای «اموات» در جستجو حضور دارند، اما نوع آنها «غیرشهید» است و در آمار شهدا نباید شمرده شوند.
- «شهید گمنام» رکورد معتبر شهید است و باید هم در جستجو و هم در آمار شهدا حضور داشته باشد.
- خانه خالی یا مقدار `?` به معنی نبود اطلاعات است و خطای داده محسوب نمی‌شود؛ `?` هنگام نرمال‌سازی به مقدار خالی تبدیل می‌شود.
- سال دو رقمی مانند `57` و `62` برای جستجو به `1357` و `1362` نرمال می‌شود.
- توضیحات قابل جستجو نیست.

## وضعیت

این پوشه باید شامل فایل‌های اصلی Excel باشد. به دلیل باینری بودن فایل‌های Excel، قرار دادن آنها در Git باید با روش مناسب Git/PowerShell انجام شود؛ محتوای فایل‌ها نباید با تبدیل متنی بازسازی شود.
