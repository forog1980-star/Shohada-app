# داده مرجع جستجوی کل شهدا

این پوشه محل نگهداری فایل مرجع داده‌های ماژول «جستجوی کل شهدا» است.

## فایل اصلی

- `golzar_martyrs.xlsx`

## ساختار فایل

فایل Excel شامل دو برگه مستقل است:

1. `golzar_martyrs` — اطلاعات شهدای قطعات اصلی گلزار
2. `outside_golzar_martyrs` — اطلاعات قطعات عمومی بهشت زهرا و رکوردهای خارج از مجموعه اصلی

ساختار و محتوای داده‌ها در این مرحله نباید تغییر داده شود. رکوردهای اموات و شهدای گمنام نیز بخشی از داده مرجع هستند و باید حفظ و قابل جستجو باقی بمانند.

## قطعات رسمی فیلتر

17، 21، 24، 26، 27، 28، 29، 40، 44، 53، قطعات عمومی بهشت زهرا

## اصل داده مرجع

این فایل پس از انتقال نهایی، منبع داده نسخه وب ماژول جستجوی کل شهدا خواهد بود تا وابستگی اجرای برنامه به فایل محلی `ShohadaData` حذف شود.

**نکته:** فایل Excel باید بدون تغییر محتوایی در این مسیر قرار گیرد.
